2. The Table Read

All 7 tables read the same scene at the same time. You float. Nobody performs for the whole room.

Actor (3 per table) Narrator: stage directions + minor lines Power Tracker: tallies power moves
One 20-minute Scene block
2 minSet

One-line setup. Post the focus question.

8 minRead

Every table reads to the FREEZE line marked in the script.

3 minFreeze

Table answers the question. Tracker reports the tally.

5 minRead

Finish the scene.

2 minReport

Cold-call one table. Prove it with a line.

Rotate roles every scene so the quiet kids get a turn as Actor and the loud ones get a turn as Tracker.
